Finding students who could excel, before they are overlooked

Can the first 30 days of observable engagement identify students likely to earn a Distinction, while there is still time for a teacher to act?

What to sayMost education prediction projects ask which students might fail. I wanted to turn that around and ask who might be capable of excelling, but could go unnoticed in a crowded or under resourced classroom. The important word is early. A prediction after final exams is too late to help, so every model in this project only sees the first 30 days.

The accuracy trap

The highest four class accuracy came from a model that almost stopped predicting Distinction

52.6%Raw forest accuracy
9.9%Distinction recall
48.8%Tuned forest accuracy
49.1%Tuned Distinction recall

The flat training score at one and much lower cross validation score show severe variance. Grid search selected depth 12, leaf size 4, and half the features per split.

Tuning lowered headline accuracy, but it made the model five times better at finding the class the project actually cares about.
What to sayThis was the most important diagnostic. The raw forest had the best four class accuracy, but it found only about one in ten Distinction students. The learning curve explains why: it memorized the training data. After tuning the tree depth and leaf size, overall accuracy fell slightly, but Distinction recall rose to nearly one in two. That is a better model for this problem, even though the accuracy number is lower.

What to sayThe first neural network gave me a clear overfitting pattern. Training kept improving while validation stopped. I then added dropout and L2 regularization, and the curves became much healthier. The Functional model processed behaviour and demographics separately because the correlation analysis showed they carried different information. It achieved similar performance with fewer parameters, but deep learning still did not beat the tuned forest. On this medium sized tabular dataset, added complexity was not automatically useful.

I would not lead with the 84 percent accuracy, because predicting nobody as Distinction would score even higher. 70:50
What the model still does not know

The repeated errors and the evaluation design set clear boundaries on the claim

Distinction versus Pass

At day 30, both groups can look engaged and capable. The difference may not exist clearly in the data yet.

Withdrawn versus Fail

Withdrawal can be caused by work, illness, family, or finances, which the clickstream cannot observe.

Record level split

About 19% of rows come from students with more than one course record. A stronger split should keep each student in only one partition.

Repeated test evaluation

The same test set was scored across all experiments. Future model selection should use validation, then open the final test set once.

Transfer to African schools

The data is from UK distance learners in 2013 and 2014. The method may transfer, but the trained weights should not be assumed to.

Uncertainty matters

A real system should include an uncertain review band instead of forcing every student into a confident answer.

What to sayThe confusion matrices kept showing the same two difficult boundaries, regardless of model. That suggests the limitation is partly in the data, not only the algorithms. I also need to be honest about evaluation. The split was by student course record, so the next version should group by student. And because I reviewed test results after every experiment, the cleanest future design would keep one final test set completely locked until model selection is finished.

Backup questions

Short answers for the questions most likely to come up

Why is accuracy misleading here?

Pass is the largest class, and Distinction is rare. A model can gain accuracy by mostly predicting common classes while missing the students I care about.

Why use macro F1?

It calculates the F1 score for each class and gives every class equal weight. Distinction therefore cannot disappear behind the much larger Pass class.

What does area under the curve mean?

It measures how well the model ranks positive examples above negative ones across many thresholds. A value of 0.5 is random and one is perfect.

Why did tuning lower accuracy?

The raw forest gained accuracy by favoring common classes. Tuning reduced memorization and allowed class weights to influence decisions, so it found more Distinction students.

Why did SMOTE not help?

Distinction and Pass overlap heavily. Synthetic Distinction points were probably created inside that overlap, so resampling did not create a cleaner boundary.

Why did deep learning not win?

This is medium sized tabular data with engineered features. Tree models are often very strong in that setting because they handle irregular interactions naturally.

What did dropout and L2 change?

They reduced overfitting. Training improved more slowly, but validation stayed closer instead of getting worse while training kept improving.

Why use a Functional model?

The heatmap showed behaviour and demographics were mostly separate feature groups. The Functional API let each group learn through its own branch before combining them.

Why not claim the binary model is 84% successful?

Because predicting every student as not Distinction would score about 89%. The useful evidence is its ranking ability and Distinction recall.

What would you improve first?

I would split by student, keep the final test set locked, calibrate probabilities, and choose the threshold using a real school’s review capacity.
